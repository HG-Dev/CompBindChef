## Dependencies

### CsprojModifier
This package uses [CsprojModifier](https://github.com/Cysharp/CsprojModifier) to enable the use of C#10 and nullable in csproj files generated by Unity. This requires the use of a LangVersion.props files given to Project Settings > Editor > C# Project Modifier as an "additional project import" for the sake of your IDE, and the inclusion of csc.rsp files for each assembly definition, which contain arguments used by Unity when compiling C#.
